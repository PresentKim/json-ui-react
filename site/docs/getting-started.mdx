# 시작하기

<DownloadButton />

## 명령어

요구 사항은 Node 22 이상이다.

```bash
npm install
npm test
npm run build:addon   # dist/json-ui-react-examples.mcaddon
npm run site:build    # 이 문서 사이트
```

## 애드온 설치

1. 위 버튼으로 `json-ui-react-examples.mcaddon`을 내려받는다.
2. 파일을 열면 마인크래프트가 행동팩과 리소스팩을 가져온다.
3. 월드에 두 팩을 모두 켜고, 베타 API(`@minecraft/server` 2.0.0)를 쓰는 환경인지 확인한다.

## 예시 열기

/scriptevent jur:open <예시id>

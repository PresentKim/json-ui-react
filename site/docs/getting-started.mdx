# 시작하기


## 명령어

요구 사항은 Node 22 이상이다.

```bash
npm install
npm test
npm run build:addon   # dist/json-ui-react-examples.mcaddon
npm run site:build    # 이 문서 사이트
```

## 애드온 설치

1. 상단 오른쪽 "통합 테스트 애드온 다운로드"로 `json-ui-react-examples-v<버전>-<커밋>.mcaddon`을 내려받는다. 이 애드온 하나에 모든 예시가 들어 있다.
2. 파일을 열면 마인크래프트가 행동팩과 리소스팩을 가져온다.
3. 행동팩 이름은 `json-ui-react Examples BP vX.Y.Z` 형태이다. 게임 안 글자는 영어이다.
4. 월드에 두 팩을 모두 켜고, 베타 API(`@minecraft/server` 2.0.0)를 쓰는 환경인지 확인한다.
5. 게임의 팩 이름 끝 버전(v1.1.0)과 설명 둘째 줄(버전 · 커밋 · 날짜)이 내려받은 파일명과 같은지 확인한다.

## 예시 열기

**막대기를 쓴다**(PC는 우클릭, 모바일은 길게 누르기). 예시 고르기 창(제목 `json-ui-react Examples`)이 열리고, 고른 예시 폼이 바로 뜬다. 월드에 처음 들어올 때 막대기가 없으면 하나 받는다.

명령으로 열 수도 있다. `/scriptevent jur:open`만 쓰면 고르기 창이 열린다.

```text
/scriptevent jur:open <예시id>
```

| 예시 id | 폼 제목 | 버튼 수 | 페이지 |
| --- | --- | --- | --- |
| `router` | `jur:ro` | 4 | [라우터](components/router) |
| `tabs-inside` | `jur:ti` | 6 | [탭: 탭 안에 내용](components/tabs-inside) |
| `tabs-follow` | `jur:tf` | 6 | [탭: 표시 바인딩](components/tabs-follow) |
| `tabs-lazy` | `jur:tl` | 6 | [탭: 고를 때 팩토리](components/tabs-lazy) |
| `slot-grid` | `jur:sg` | 24 | [고정 칸 그리드](components/slot-grid) |
| `virtual-list-500` | `jur:v5` | 500 | [가상 목록 500칸](components/virtual-list-500) |
| `virtual-list-2000` | `jur:v2` | 2000 | [가상 목록 2000칸](components/virtual-list-2000) |
| `research` | `jur:re` | 2022 | [연구 화면](components/research) |

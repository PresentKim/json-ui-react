# 탭: 탭 안에 내용 (방식 B)

탭을 켠 얼굴 안에 패널을 넣는 방식(B)


각 탭 토글의 켠 얼굴 안에 패널을 넣는다. 토글 상태가 곧 표시 상태라 바인딩이 필요 없다.

## 쓰는 API

| 이름 | 설명 |
| --- | --- |
| `TabBar` | [API 레퍼런스](../api) |
| `radioToggleBody` | [API 레퍼런스](../api) |
| `SlotGrid` | [API 레퍼런스](../api) |

## JSX로 쓰기

`TabBar`, `radioToggleBody`, `SlotGrid`를 쓴다. 탭을 켠 얼굴 안에 패널을 넣는 방식이다.

| JSX | 낮춰진 JSON UI |
| --- | --- |
| `<TabBar>` | 가로 `stack_panel` + 라디오 `toggle` 8상태 |
| `<SlotGrid>` | 줄 `stack_panel` + `collection_index` 칸 |

## 근거 규칙

INP-10, INP-11, INP-13

## 통합 애드온에서 실행 방법

상단 오른쪽 "통합 테스트 애드온 다운로드"로 받은 애드온에서 막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다. 게임 안 글자는 영어이며, 고르기 창(`json-ui-react Examples`)의 메뉴 라벨은 `Tabs: content inside the toggle`이다.

버튼 6개, 폼 제목 `jur:ti`.

```text
/scriptevent jur:open tabs-inside
```

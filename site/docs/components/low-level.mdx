# 타입이 붙은 저수준 컨트롤

`json-ui-react`는 바닐라 컨트롤 타입마다 속성 타입을 갖는다. 소문자 태그(`<stack_panel>`)와 PascalCase 부품(`<StackPanel>`)을 모두 쓸 수 있고, 규칙을 어기는 속성은 **컴파일 때** 걸린다.

## 타입 오류 예

```tsx
import { Label, Toggle, Panel } from "json-ui-react";

// COL-02: label에는 collection_index를 쓸 수 없다
// @ts-expect-error
<label text="a" collection_index={0} />;

// COL-01: collection_name은 stack_panel, grid, collection_panel 전용이다
// @ts-expect-error
<panel collection_name="x" />;

// INP-10: toggle은 8개 상태 키(checked_control … unchecked_locked_hover_control)가 모두 있어야 한다
// @ts-expect-error
<toggle toggle_name="t" checked_control="a" />;
```

고수준 `Screen`과 이름이 겹치는 저수준 부품은 `LowScreen`, `LowLabel`처럼 `Low` 접두로 낸다.

## 바인딩 빌더

```ts
import { bind, checkBindings } from "json-ui-react";

const list = [
  bind.global("#title_text"),
  bind.view("(#hover_text = 'a')", "#visible"),
  bind.collection("#item_name", "container_items", { condition: "once" }),
  bind.details("container_items"),
];
checkBindings(list, "controls.0.bindings"); // 규칙 ID가 붙은 진단 목록
```

## 식 빌더

```ts
import { E, checkExpr } from "json-ui-react";

E.prop("#count").gt(0).and(E.prop("#name").neq(E.str("x"))).toString();
E.num(0.5).toString(); // ".5" (EXP-27: 소수는 앞 0 없이)
checkExpr("(#a > 0.5)", "bindings.0"); // EXP-27 진단
```

## 애니메이션 빌더

```ts
import { animation, chain } from "json-ui-react";

animation({ anim_type: "alpha", from: 0, to: 1, duration: 0.3, easing: "linear" });
chain("fx", {
  a: { anim_type: "alpha", from: 0, to: 1, duration: 0.2 },
  b: { anim_type: "alpha", from: 1, to: 0, duration: 0.2 },
}, ["a", "b"], { loop: true }); // a.next = "@fx.b", b.next = "@fx.a"
```

`duration`이 0 이하이거나 `flip_book`에 `frame_count`가 없으면 규칙 ID가 붙은 오류를 던진다. 규칙 조회와 빌드 검사(`runChecks`), 배치 질의(`explainPlacement`, `solvePlacement`)는 [규칙 API](../reference/rules-api.mdx)를 본다.

## 계층 구조

```text
규칙 레지스트리 (src/rules)
  → 타입 컨트롤, PascalCase (src/controls)
  → 빌더: bind / E / anim / modify
  → 배치 solvePlacement / 검사 runChecks
  → 고수준: src/high, src/entity, src/components
  → 예시
```

위에서 아래로만 의존한다. 고수준 부품은 PascalCase 컨트롤과 빌더만으로 짜고, 소문자 태그나 `binding_type` 객체를 직접 쓰지 않는다. 예시도 고수준과 타입 컨트롤만 가져온다.

## modify 빌더

```ts
import { modify, modifications } from "json-ui-react";

modifications(
  modify.insertBack("controls", [{ hud_extra: {} }]),
  modify.insertAfter("controls", { hud_a: {} }, [{ hud_b: {} }]),
  modify.remove("bindings", { binding_name: "#old" }),
);
// { modifications: [{ array_name: "controls", operation: "insert_back", value: [...] }, ...] }
```

연산 11개(`insertBack`, `insertFront`, `insertAfter`, `insertBefore`, `moveBack`, `moveFront`, `moveAfter`, `moveBefore`, `swap`, `replace`, `remove`)가 MOD-14와 같고, 타입 `Modification`, `ModOperation`, `ModArray`를 함께 낸다.

## 고수준 부품은 어떻게 짜이나

`src/entity/data.tsx`의 `SlotText`는 PascalCase `Label`과 바인딩 빌더만으로 쓴다. 배치(칸 읽기 래퍼)는 `reader`가 `solvePlacement`에 맡긴다.

```tsx
export function SlotText(p: SlotTextProps): JuiElement {
  const slot = pick("SlotText", p.slot, p.index);
  return reader(
    <LabelCtl {...({ name: p.name, text: "#text", localize: false, ...textProps(p),
      bindings: [collect("#hover_text"), view(p.raw ? "#hover_text" : CLEAN, "#text")] } as ElementProps<"label">)} />,
    slot,
  );
}
```

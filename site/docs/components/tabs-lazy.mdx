# 탭: 고를 때 팩토리 (방식 D)

탭을 고를 때만 패널을 팩토리로 만드는 방식(D)


첫 탭만 미리 만들고 나머지는 토글 상태에 묶은 팩토리로 고를 때 만든다. 첫 탭에는 `lazyPane(0)`을 쓸 수 없다.

## 쓰는 API

| 이름 | 설명 |
| --- | --- |
| `TabBar` | [API 레퍼런스](../api) |
| `SlotGrid` | [API 레퍼런스](../api) |
| `bind.view` | [API 레퍼런스](../api) |

## JSX로 쓰기

`TabBar`, `SlotGrid`, `bind.view`를 쓴다. 탭을 고를 때만 패널을 팩토리로 만든다.

| JSX | 낮춰진 JSON UI |
| --- | --- |
| `<TabBar>` | 가로 `stack_panel` + 라디오 `toggle` 8상태 |
| `<SlotGrid>` | 줄 `stack_panel` + `collection_index` 칸 |
| `useTabs().lazyPane` | `factory` + `#collection_length` 바인딩 |

## 통합 애드온에서 실행 방법

상단 오른쪽 "통합 테스트 애드온 다운로드"로 받은 애드온에서 막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다.

버튼 6개, 폼 제목 `jur:tl`.

```text
/scriptevent jur:open tabs-lazy
```

# 탭: 고를 때 팩토리 (방식 D)

탭을 고를 때만 패널을 팩토리로 만드는 방식(D)


`<Tabs mode="lazy">`는 첫 탭만 미리 만들고 나머지는 토글 상태에 묶은 팩토리로 고를 때 만든다. 첫 탭을 팩토리로 만들면 처음 열 때 비므로, 첫 탭을 미리 만드는 일은 자동이다.

## 쓰는 API

| 이름 | 설명 |
| --- | --- |
| `Screen` | 화면 하나: [API 레퍼런스](../api#high) |
| `Tabs` | 클라이언트 탭: [API 레퍼런스](../api#high) |
| `Tab` | 탭 하나: [API 레퍼런스](../api#high) |
| `ButtonList` | 아이콘 + 글자 버튼 세로 목록: [API 레퍼런스](../api#high) |

## JSX로 쓰기

`mode="lazy"`만 다르고 코드 모양은 방식 B와 같다. 첫 탭을 따로 처리할 필요가 없다.

| 고수준 요소 | 낮춰진 JSON UI | 근거 규칙 |
| --- | --- | --- |
| `<Screen>` | 창 정의 `tl@jur.window` + 라우터 항목(폼 제목 `jur:tl`) | HOST-06, COL-22, COL-39, COL-47 |
| `<Tabs name="tabs" mode="lazy">` | 탭 줄 `tl_tabs`: 가로 `stack_panel` + 라디오 `toggle` 8상태 | INP-10, INP-11, INP-13 |
| 첫 `<Tab>`의 내용 | `tl_pane_0`을 미리 만들고 토글 상태 바인딩으로만 보인다 | INP-13, COL-47 |
| 그 밖의 `<Tab>`의 내용 | `tl_lazy_1`: `factory` + 탭 토글을 `#collection_length`에 묶는 바인딩. 고를 때 판을 만든다 | INP-13, COL-47 |
| `<ButtonList name="tab1" count={2} />`, `<ButtonList name="tab2" count={2} />` | 탭마다 `@jur.btn` 버튼 2개: 세로 `stack_panel` 안의 줄 2개(`collection_name: form_buttons`), 줄마다 고정 `collection_index` 칸 | COL-38, COL-50 |

## 서버에서 열기

행동팩은 `buildScreens`가 만든 `scripts/generated/screens.js`의 `openScreen(player, id, data)`로 화면을 연다. `data`의 키는 컴포넌트의 `name`이고, 값은 버튼 목록이다. 버튼은 `[글자, 아이콘]`이다. 반환값은 `Promise<null | { name, index }>`로, 창을 닫으면 `null`이고 버튼을 누르면 어느 컴포넌트(`name`)의 몇 번째(`index`)인지 돌려준다. 컴포넌트의 칸 수보다 많이 보내면 오류이고, 모자라면 빈 칸 표식(`§0§e§r`)으로 채운다.

```js
import { openScreen } from "./generated/screens.js";

openScreen(player, "tabs-lazy", {
  // <Tabs name="tabs">: 탭 글자와 아이콘
  tabs: [["Tab 1", "textures/items/book_normal"], ["Tab 2", "textures/items/emerald"]],
  // <ButtonList name="tab1" count={2}>, <ButtonList name="tab2" count={2}>
  tab1: [["Tab 1: Apple", "textures/items/apple"], ["Tab 1: Bread", "textures/items/bread"]],
  tab2: [["Tab 2: Diamond", "textures/items/diamond"], ["Tab 2: Gold Ingot", "textures/items/gold_ingot"]],
}).then((hit) => {
  if (!hit) return; // 취소
  // hit: { name: "tab1" | "tab2", index: 0..1 }
});
```

생성 모듈의 `LAYOUTS["tabs-lazy"]`는 컴포넌트가 버튼 번호를 어떻게 나눠 받았는지 보여 준다. 아래는 prebuild가 생성 모듈에서 뽑은 것이다.

## 낮춤 결과

`jur:tl` 화면이 컴파일된 JSON UI 정의의 일부다. 탭 줄(`tl_tabs`), 팩토리로 만드는 둘째 탭(`tl_lazy_1`), 창 정의(`tl@jur.window`)다. 빌드할 때 prebuild가 `rp/ui`에서 뽑는다.

## 통합 애드온에서 실행 방법

상단 오른쪽 "통합 테스트 애드온 다운로드"로 받은 애드온에서 막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다. 게임 안 글자는 영어이며, 고르기 창(`json-ui-react Examples`)의 메뉴 라벨은 `Tabs: built on first select`이다.

버튼 6개, 폼 제목 `jur:tl`.

```text
/scriptevent jur:open tabs-lazy
```

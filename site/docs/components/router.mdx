# 라우터

제목 접두 6바이트로 화면을 고르는 라우터와 버튼 4개 목록


`<Screen>` 하나와 `<ButtonList>` 하나로 버튼 4개 화면을 쓴다. 화면 고르기는 `buildScreens`가 만드는 단일 라우터(`ScreenRouter`)가 맡는다. 라우터는 폼 제목의 접두 6바이트(`jur:ro`)만 비교해 화면을 고르므로 모든 제목의 바이트 길이가 같다. 그래서 화면 파일에는 라우터가 나오지 않는다.

## 쓰는 API

| 이름 | 설명 |
| --- | --- |
| `Screen` | 화면 하나: [API 레퍼런스](../api#high) |
| `ButtonList` | 아이콘 + 글자 버튼 세로 목록: [API 레퍼런스](../api#high) |
| `buildScreens` | 화면들을 한 팩으로: [API 레퍼런스](../api#high) |

## JSX로 쓰기

`<Screen>`과 `<ButtonList>`를 쓴다. `<Screen>`은 `id`(행동팩이 부르는 이름)와 `title`(창 위에 보이는 제목)을 받는다. `<ButtonList>`의 `name`은 서버 데이터의 키가 되고, `count`는 1에서 5까지다(판 높이 안에 들어가는 수). 더 긴 목록은 `<VirtualList>`를 쓴다.

| 고수준 요소 | 낮춰진 JSON UI | 근거 규칙 |
| --- | --- | --- |
| `<Screen id="router" title="…">` | 창 정의 `ro@jur.window`(제목은 정적 라벨) + 라우터 항목(폼 제목 `jur:ro`) | HOST-06, COL-22, COL-39, COL-47 |
| `<ButtonList name="buttons" count={4} />` | `@jur.btn` 버튼 4개: 세로 `stack_panel` 안의 줄 4개(`collection_name: form_buttons`), 줄마다 고정 `collection_index` 칸 | COL-38, COL-50 |

## 서버에서 열기

행동팩은 `buildScreens`가 만든 `scripts/generated/screens.js`의 `openScreen(player, id, data)`로 화면을 연다. `data`의 키는 컴포넌트의 `name`이고, 값은 버튼 목록이다. 버튼은 `[글자, 아이콘]`이다. 반환값은 `Promise<null | { name, index }>`로, 창을 닫으면 `null`이고 버튼을 누르면 어느 컴포넌트(`name`)의 몇 번째(`index`)인지 돌려준다. 컴포넌트의 칸 수보다 많이 보내면 오류이고, 모자라면 빈 칸 표식(`§0§e§r`)으로 채운다.

```js
import { openScreen } from "./generated/screens.js";

openScreen(player, "router", {
  buttons: [
    ["Title prefix jur:", "textures/items/apple"],
    ["Lookup by 6 bytes", "textures/items/bread"],
    ["Pick one screen", "textures/items/diamond"],
    ["4 buttons in a row", "textures/items/emerald"],
  ],
}).then((hit) => {
  if (!hit) return; // 취소
  // hit: { name: "buttons", index: 0..3 }
});
```

생성 모듈의 `LAYOUTS["router"]`는 컴포넌트가 버튼 번호를 어떻게 나눠 받았는지 보여 준다. 아래는 prebuild가 생성 모듈에서 뽑은 것이다.

## 통합 애드온에서 실행 방법

상단 오른쪽 "통합 테스트 애드온 다운로드"로 받은 애드온에서 막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다. 게임 안 글자는 영어이며, 고르기 창(`json-ui-react Examples`)의 메뉴 라벨은 `Screen router`이다.

버튼 4개, 폼 제목 `jur:ro`.

```text
/scriptevent jur:open router
```

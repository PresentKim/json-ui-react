# 라우터

제목 접두 6바이트로 화면을 고르는 라우터와 버튼 4개 한 줄


ScreenRouter는 `collection_panel`과 팩토리, `property_bag` 제목 조회로 화면을 고른다. 제목은 접두 6바이트(`jur:ro`)만 비교하므로 모든 제목의 바이트 길이가 같아야 한다.

## 쓰는 API

| 이름 | 설명 |
| --- | --- |
| `ScreenRouter` | [API 레퍼런스](../api) |
| `SlotGrid` | [API 레퍼런스](../api) |
| `createSlots` | [API 레퍼런스](../api) |

## JSX로 쓰기

`ScreenRouter`, `SlotGrid`, `createSlots`를 쓴다. 이 화면 파일은 버튼 4개 한 줄(`ButtonRow` = `SlotGrid` 한 줄)만 그리고, 제목으로 화면을 고르는 `ScreenRouter`는 빌드 스크립트가 모든 예시를 묶어 만든다.

| JSX | 낮춰진 JSON UI |
| --- | --- |
| `<ScreenRouter>` | `collection_panel` + 팩토리 + `property_bag` 제목 조회 |
| `<SlotGrid>` | 줄 `stack_panel` + `collection_index` 칸 |

## 통합 애드온에서 실행 방법

상단 오른쪽 "통합 테스트 애드온 다운로드"로 받은 애드온에서 막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다. 게임 안 글자는 영어이며, 고르기 창(`json-ui-react Examples`)의 메뉴 라벨은 `Screen router`이다.

버튼 4개, 폼 제목 `jur:ro`.

```text
/scriptevent jur:open router
```

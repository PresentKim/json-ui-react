# 고정 칸 그리드

고정 칸 3x8 그리드와 선택 상세


세로 `stack_panel` 안의 가로 줄에 칸을 직속 자식으로 두고 칸마다 고정 `collection_index`를 준다. 부모가 `panel`이면 COL-50 때문에 전부 0을 그린다.

## 쓰는 API

| 이름 | 설명 |
| --- | --- |
| `SlotGrid` | [API 레퍼런스](../api) |
| `createSlots` | [API 레퍼런스](../api) |

## JSX로 쓰기

`SlotGrid`, `createSlots`를 쓴다. 3x8 고정 칸과 선택 상세를 그린다.

| JSX | 낮춰진 JSON UI |
| --- | --- |
| `<SlotGrid>` | 세로 `stack_panel` 안의 줄 `stack_panel` + `collection_index` 칸 |
| `slots.range` | 연속 버튼 번호 구간 |

## 근거 규칙

COL-38, COL-50, INP-35, BND-32

## 통합 애드온에서 실행 방법

상단 오른쪽 "통합 테스트 애드온 다운로드"로 받은 애드온에서 막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다. 게임 안 글자는 영어이며, 고르기 창(`json-ui-react Examples`)의 메뉴 라벨은 `Slot grid with selection detail`이다. 칸을 고르기 전 상세 자리에는 `Pick a slot.`이 보인다.

버튼 24개, 폼 제목 `jur:sg`.

```text
/scriptevent jur:open slot-grid
```

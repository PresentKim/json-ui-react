# 탭: 표시 바인딩 (방식 C)

패널이 토글 상태 바인딩을 따라 보이는 방식(C)


패널이 `#toggle_state`를 `#visible`에 묶어 탭을 따라 보인다. 라우터 아래 컬렉션 바인딩에는 `binding_condition: "always"`가 필요하다.

## 쓰는 API

| 이름 | 설명 |
| --- | --- |
| `TabBar` | [API 레퍼런스](../api) |
| `SlotGrid` | [API 레퍼런스](../api) |
| `bind.view` | [API 레퍼런스](../api) |

## JSX로 쓰기

`TabBar`, `SlotGrid`, `bind.view`를 쓴다. 패널이 토글 상태 바인딩을 따라 보인다.

| JSX | 낮춰진 JSON UI |
| --- | --- |
| `<TabBar>` | 가로 `stack_panel` + 라디오 `toggle` 8상태 |
| `<SlotGrid>` | 줄 `stack_panel` + `collection_index` 칸 |
| `useTabs().paneBinding` | `#toggle_state` -> `#visible` 바인딩 |

## 근거 규칙

INP-13, COL-47, BND-32

## 통합 애드온에서 실행 방법

상단 오른쪽 "통합 테스트 애드온 다운로드"로 받은 애드온에서 막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다.

버튼 6개, 폼 제목 `jur:tf`.

```text
/scriptevent jur:open tabs-follow
```

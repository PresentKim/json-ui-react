# 탭: 표시 바인딩 (방식 C)

패널이 토글 상태 바인딩을 따라 보이는 방식(C)

<DownloadButton small />

패널이 `#toggle_state`를 `#visible`에 묶어 탭을 따라 보인다. 라우터 아래 컬렉션 바인딩에는 `binding_condition: "always"`가 필요하다.

## 낮춤 결과

`jur:tf` 화면이 컴파일된 JSON UI 정의의 일부다. 빌드할 때 prebuild가 `rp/ui`에서 뽑는다.

<Excerpt data={tabs_follow} />

## 근거 규칙

INP-13, COL-47, BND-32

## 게임에서 열기

막대기를 써서 예시 고르기 창에서 고르거나, 명령을 실행한다.

버튼 6개, 폼 제목 `jur:tf`.

```text
/scriptevent jur:open tabs-follow
```

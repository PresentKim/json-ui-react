# 라이선스 적용 방법

이 사이트는 json-ui-react 저장소의 코드와 예시를 설명하고, JSON UI 규칙과 실측은 bedrock-research 위키에 기댄다. 어느 페이지가 어느 출처를 쓰는지는 페이지 하단의 출처 표에 있고, 전체 목록은 [출처 목록](./sources.mdx)에 라이선스별로 모았다.

## 발췌와 다시 쓰기

출처 레지스트리(`site/sources/*.json`)의 `redistribute` 값이 기준이다.

- `redistribute: true`인 출처는 원문을 `<Excerpt>` 상자로 옮길 수 있다. 상자 머리에 출처 제목, 원문 경로, 라이선스, 커밋을 적는다.
- `redistribute: false`인 출처는 원문을 옮기지 않고 사실만 다시 쓴다. 검사 스크립트(`npm run site:check`)는 이런 출처를 `<Excerpt>`로 쓰면 오류로 처리한다.

컴포넌트 페이지의 "JSX로 쓰기", "서버에서 열기", "낮춤 결과" 코드 상자는 이 저장소의 소스(`example/`, `src/`)와 그 빌드 결과를 빌드할 때 그대로 읽어 온 것이다.

## 출처별 처리

| 출처 | 처리 |
| --- | --- |
| 이 저장소(`json-ui-react`) | 코드와 예시를 그대로 보인다. 저장소에 LICENSE 파일이 없어 라이선스는 아직 정해지지 않았고, 권리는 저장소 소유자에게 있다 |
| bedrock-research 위키(`bedrock-research`) | 규칙 ID와 실측 사실만 인용하고 원문을 옮기지 않는다. 위키 저장소에는 LICENSE 파일이 없고, 위키 본문은 비상업 이용 조건(위키의 README, NOTICE.md)을 따른다 |
| Microsoft Learn(`ms-learn`) | 문서는 CC BY 4.0, 코드는 MIT다. 이 사이트는 `@minecraft/server-ui`, `@minecraft/server` 같은 API 이름과 동작 사실만 쓰고 발췌하지 않는다 |
| Mojang bedrock-samples(`bedrock-samples`) | 모든 권리가 Mojang에 있다. 바닐라 정의 이름(`common.scrolling_panel` 등)과 동작 사실만 쓴다 |

## 이용자가 지킬 것

1. **출처 유지**: 이 사이트의 내용을 옮길 때는 해당 페이지의 출처 표를 함께 옮긴다.
2. **저장소 라이선스**: json-ui-react의 라이선스가 정해지기 전에는 코드를 재배포하기 전에 저장소 소유자에게 확인한다.
3. **상표**: Minecraft는 Mojang AB와 Microsoft의 상표다. 이 사이트는 Mojang이나 Microsoft와 관계가 없는 비공식 자료다.

이 문서는 법률 자문이 아니다. 확실하지 않은 이용은 원 저장소의 라이선스 파일을 직접 읽고 판단한다.

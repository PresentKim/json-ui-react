# json-ui-react

<DownloadButton />

TSX와 훅으로 쓴 서버 폼 화면을 **정적 JSON UI**와 **서버 버튼 배치 모듈**로 컴파일한다. 런타임 의존은 0이고, 같은 입력이면 바이트가 같은 출력이 나온다.

## 왜 빌드 시점 컴파일인가

배드락 JSON UI에는 JS 런타임이 없어서 화면 구조가 리소스팩에 정적으로 박힌다. 라우터, 라디오 탭, 고정 `collection_index` 칸, 버튼 번호 배치(`102 + 20k + 19`)를 손으로 맞추면 JSON과 서버 코드가 어긋나기 쉽다. 빌드 시점에 둘을 한 번에 만들면 어긋날 수 없다.

## 파이프라인

| 단계 | 하는 일 |
| --- | --- |
| TSX 화면 | 컴포넌트와 훅으로 화면을 쓴다 |
| 자체 JSX 런타임 | React 없이 요소 트리를 만든다 |
| ControlNode 트리 | `render`, `toBody`가 JSON UI 컨트롤 모양으로 낮춘다 |
| Pack | 네임스페이스별 정의를 모아 `ui/*.json` 묶음을 만든다 |
| Slots | 서버 버튼 번호를 할당하고 서버 모듈(JS)을 만든다 |
| Lint | 생성된 JSON을 규칙 ID가 붙은 진단으로 검사한다 |

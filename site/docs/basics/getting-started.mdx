# 시작하기

예시 8개가 든 통합 테스트 애드온을 게임에 넣고 예시를 여는 방법이다. 라이브러리로 첫 화면을 직접 만들려면 [빠른 시작](./quick-start.mdx)을 본다.

## 명령어

```bash
npm install
npm test
npm run build:addon   # dist/json-ui-react-examples.mcaddon
npm run site:build    # 이 문서 사이트
```

## 애드온 설치

예시 8개가 든 통합 테스트 애드온으로 위 과정의 결과를 게임에서 바로 확인할 수 있다.

1. 상단 오른쪽 "통합 테스트 애드온 다운로드"로 `json-ui-react-examples-v<버전>-<커밋>.mcaddon`을 내려받는다. 이 애드온 하나에 모든 예시가 들어 있다.
2. 파일을 열면 마인크래프트가 행동팩과 리소스팩을 가져온다.
3. 행동팩 이름은 `json-ui-react Examples BP vX.Y.Z` 형태이다. 게임 안 글자는 영어이다.
4. 월드에 두 팩을 모두 켜고, 베타 API(`@minecraft/server` 2.0.0)를 쓰는 환경인지 확인한다.
5. 게임의 팩 이름 끝 버전(예: v1.3.0)과 설명 둘째 줄(버전 · 커밋 · 날짜)이 내려받은 파일명과 같은지 확인한다.

## 예시 열기

**막대기를 쓴다**(PC는 우클릭, 모바일은 길게 누르기). 예시 고르기 창(제목 `json-ui-react Examples`)이 열리고, 고른 예시 폼이 바로 뜬다. 월드에 처음 들어올 때 막대기가 없으면 하나 받는다.

명령으로 열 수도 있다. `/scriptevent jur:open`만 쓰면 고르기 창이 열린다.

```text
/scriptevent jur:open <예시id>
```

예시 8개는 모두 고수준 API로 쓴다. 연구 화면은 그중 가장 큰 예제다.

| `tabs-inside` | `jur:ti` | 6 | [탭: 탭 안에 내용](../components/tabs-inside.mdx) |

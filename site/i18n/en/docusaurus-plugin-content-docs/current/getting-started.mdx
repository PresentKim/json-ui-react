# Getting started

## Quick start

Node 22 or later is required. Making one screen and opening it in the game takes four steps. The code below is the same as the [router example](components/router).

**1. Wire the JSX runtime into `tsconfig.json`.**

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "json-ui-react"
  }
}
```

**2. Write the screen in TSX.** One screen is one `<Screen>`. `id` is the name the behavior pack uses to call the screen, and the `name` of `<ButtonList>` is a key in the server data.

```tsx
// screens/router.tsx
import { Screen, ButtonList } from "json-ui-react";

export default (
  <Screen id="router" title="Router: screen picked by title prefix">
    <ButtonList name="buttons" count={4} />
  </Screen>
);
```

**3. Build the pack with `buildScreens`.** `files` in the result are the resource pack's `ui/*.json`, and `serverModule` is the generated module that goes into the behavior pack. Copy the theme textures (`themeTextures()`) into the resource pack too.

```ts
// build.ts: npx tsx build.ts
import { mkdirSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { buildScreens, themeTextures } from "json-ui-react";
import router from "./screens/router.tsx";

const built = buildScreens([router], { namespace: "jur", prefix: "jur:" });

const write = (path: string, data: string | Uint8Array) => {
  mkdirSync(dirname(path), { recursive: true });
  writeFileSync(path, data);
};
for (const [file, text] of Object.entries(built.files)) write(join("rp", file), text); // ui/*.json
for (const [file, bytes] of Object.entries(themeTextures())) write(join("rp", file), bytes); // textures/ui/jur/*
write(join("bp", "scripts", "generated", "screens.js"), built.serverModule);
write(join("bp", "scripts", "generated", "screens.d.ts"), built.serverTypes);
```

**4. Open it from the behavior pack.** Use `openScreen(player, id, data)` from the generated module `scripts/generated/screens.js`. The keys of `data` are the component `name`s, and each value is a list of `[text, icon]` buttons. You never deal with button indices; the module sends them in the screen's layout order.

```js
// bp/scripts/main.js
import { openScreen } from "./generated/screens.js";

function openRouter(player) {
  openScreen(player, "router", {
    buttons: [
      ["Title prefix jur:", "textures/items/apple"],
      ["Lookup by 6 bytes", "textures/items/bread"],
      ["Pick one screen", "textures/items/diamond"],
      ["4 buttons in a row", "textures/items/emerald"],
    ],
  }).then((hit) => {
    if (!hit) return; // canceled
    // hit: { name: "buttons", index: 0..3 }
  });
}
```

`openScreen` returns a `Promise<null | { name, index }>`. It is `null` if the window is closed; otherwise it tells you which component (`name`) and which button in it (`index`) was pressed. If you send fewer buttons than the component has cells, the missing cells are filled with the empty-cell mark (`§0§e§r`); sending more is an error. See [part 2 of the API reference](api#server) for details.

Tabs, cell grids and long lists work the same way; see the [component pages](components/router).

## Commands

```bash
npm install
npm test
npm run build:addon   # dist/json-ui-react-examples.mcaddon
npm run site:build    # this documentation site
```

## Installing the add-on

The integration test add-on, which contains all eight examples, lets you see the result of the steps above in the game right away.

1. Use "Download integration test add-on" at the top right to get `json-ui-react-examples-v<version>-<commit>.mcaddon`. This one add-on contains every example.
2. Open the file and Minecraft imports the behavior pack and the resource pack.
3. The behavior pack is named like `json-ui-react Examples BP vX.Y.Z`. All in-game text is in English.
4. Enable both packs in a world, and make sure the environment uses the beta API (`@minecraft/server` 2.0.0).
5. Check that the version at the end of the in-game pack name (for example v1.3.0) and the second line of its description (version · commit · date) match the name of the file you downloaded.

## Opening an example

**Use the stick** (right-click on PC, long-press on mobile). The example picker (titled `json-ui-react Examples`) opens, and the example form you choose appears right away. If you enter a world without a stick, you get one.

You can also open an example with a command. `/scriptevent jur:open` on its own opens the picker.

```text
/scriptevent jur:open <example-id>
```

All eight examples are written with the high-level API. The research screen is the largest of them.

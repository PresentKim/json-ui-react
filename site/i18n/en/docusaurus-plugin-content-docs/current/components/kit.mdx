# Component kit

The kit (`kit`) in `json-ui-react` is a set of reusable parts built only from PascalCase controls and the `bind`, `E` and animation builders. Every part that takes children goes through `place()`. It renders the children, checks the combination with the parent via `explainPlacement`, fixes it with `solvePlacement` when possible (leaving an **info** diagnostic), and otherwise reports an error (a warning when not strict). Diagnostics carry the rule id and the wiki url.

## Usage

```tsx
import { kit, KitSpacer, collectKit, render } from "json-ui-react";

const { result, diagnostics } = collectKit(() =>
  render(
    <kit.Repeat name="rep" collection="form_buttons" layout="stack-v" count={1}
      item={() => <kit.Column name="col"><Label name="bad" text="x" collection_index={0} /></kit.Column>} />,
  ),
);
// result: the label is already in its fixed form
// diagnostics: [{ rule: "COL-02", level: "info", url: ".../rules#col-02", ... }]

// strict: errors that cannot be fixed throw
collectKit(() => render(<kit.ItemText name="t" prop="#x" />), { strict: true }); // COL-44
```

`Spacer` clashes with the high-level name, so the top level exports it as `KitSpacer`; the `kit` namespace keeps every original name. Collect animation definitions with `defineAnims` and `takeAnims` and write them into the namespace file. The full example is `examples/kit/gallery.tsx`.

## Layout

| Part | Main props | Placement contract | Rules |
| --- | --- | --- | --- |
| `Row`, `Column` | `gap`, `align` | children via `place()` into a stack_panel | LAY-38, COL-02 |
| `Spacer` | `w`, `h`, `fill`, `axis` | no children | LAY-30 |
| `Overlay` | layer order | `place()` into a panel | layer order |
| `Align`, `Center` | `to` (9 anchors) | `place()` into a panel | LAY-16 |
| `Padding` | `inset` | panel, size expression `100% - Npx` | LAY-35 |
| `Box` | `w`, `h` | `place()` into a panel | LAY-38 |
| `ScrollArea` | `size`, `speed`, `barWidth` | wires the scroll_view role controls | LAY-42 |
| `GridLayout` | `cols`, `rows`, `cell`, `template`, `countFrom` | `place()` into a grid | LAY-30, LAY-32 |

## Visual

| Part | Main props | Placement contract | Rules |
| --- | --- | --- | --- |
| `Text` | `text` (string, `{bind}`, `{expr}`), font, color | no children | TXT, EXP-30 |
| `Icon` | `texture`, `uv`, `uvSize`, `tiled`, `nineSlice` | no children | LAY-38 |
| `Frame` | `texture`, `inset` | background + content panel via `place()` | LAY-38 |
| `ProgressBar` | `ratio` (expression), `source`, `size` | constant ratio gives a diagnostic | EXP-27 |
| `ItemIcon` | none (inside a collection) | error outside a collection | COL-44 |
| `Divider` | `orientation`, `thickness` | no children | LAY-38 |

## Data and collections

| Part | Main props | Placement contract | Rules |
| --- | --- | --- | --- |
| `ShowIf` | `when` (expression, `{has}`, `{lacks}`) | `place()` into a panel | BND-31 |
| `Switch`, `Case` | `on`, `value` | Case only inside Switch; duplicate values throw | BND-31 |
| `BindText` | `from` (property or expression) | reads a property inside a collection | BND, COL-02 |
| `Repeat` | `collection`, `layout`, `count`, `cols`, `item` | `collection_index` per item, `place()` | COL-01, COL-38, COL-50 |
| `Item` | `index` | opens a collection item scope | COL-02 |
| `ItemText` | `prop` | error outside a collection, label gets wrapped | COL-02, COL-44 |
| `KeyedFactory` | `variants`, `size` | factory with `#k` lookup | COL-28, COL-42, ANI-37 |

## Input

| Part | Main props | Placement contract | Rules |
| --- | --- | --- | --- |
| `PushButton` | `face`, state faces, `sound` | no `visible` on state children | INP-02, INP-06 |
| `ToggleBox` | `on`, `off`, `hover` | generates all 8 states | INP-10, INP-11 |
| `RadioGroup`, `Radio` | `group`, `selected`, `index` | shared `toggle_name` | INP-12, INP-35 |
| `TabGroup` | `tabs` (`id`, `on`, `off`, `pane`) | panes bound to `#toggle_state` | INP-12 |
| `TextInput` | `textBoxName`, `maxLength`, `placeholder` | edit_box | INP |
| `SliderControl` | `sliderName`, `size` | warning outside a collection | HOST-12 |

## Animation

| Part | Main props | Placement contract | Rules |
| --- | --- | --- | --- |
| `defineAnims`, `takeAnims` | namespace, definitions | `"@ns.name"` refs, registry | ANI |
| `Animated` | `anims` | `place()` into a panel, never touches `layer` | ANI-38 |
| `FadeIn`, `FadeOut` | `ns`, `duration`, `easing` | as above | ANI-09, ANI-10 |
| `SlideIn` | `from`, `to` | as above | ANI-09 |
| `Pulse` | `ns`, `duration` | looping alpha | ANI-09 |

# Virtual list, 2000 cells

A two-column virtual list of 2000 cells (the COL-49 limit)


2000 cells is the COL-49 limit. Going past it makes cells draw on top of each other, so the build reports an error.

| Name | Description |

## Writing it in JSX

Uses `VirtualList`. 2000 cells is the COL-49 limit, and going past it is a build error unless you pass `allowLarge`. The two files below are the 2000-cell entry point and the shared definitions.

| JSX | Lowered JSON UI |
| --- | --- |
| `<VirtualList>` | `grid` + `maximum_grid_items` bound to `#form_button_length` |

## Running it in the integration add-on

In the add-on you downloaded with "Download integration test add-on" at the top right, use the stick to pick the example in the picker, or run the command. In-game text is in English: the picker (`json-ui-react Examples`) lists this example as `Grid list (2000)`.

2000 buttons, form title `jur:v2`.

```text
/scriptevent jur:open virtual-list-2000
```

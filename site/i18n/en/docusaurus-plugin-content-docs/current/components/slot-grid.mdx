# Fixed-slot grid

A fixed 3x8 slot grid with a selection detail


`<SlotGrid>` builds a fixed grid of cells. The cells are direct children of horizontal rows inside a vertical `stack_panel`, and each gets a fixed `collection_index`. If the parent were a `panel`, COL-50 would make every cell draw index 0, so the component takes care of that layout. With `detail`, the icon and name of the chosen cell show in the right pane.

## Writing it in JSX

`<Screen layout="split">` divides the window into a left list and a right detail pane. `detail` works only with `split`; if it is a string, it is the hint shown in the right pane before you choose a cell. There is one `<SlotGrid>` per screen.

| High-level element | Lowered JSON UI | Rules |
| --- | --- | --- |
| `<Screen layout="split">` | Window definition `sg@jur.window_split` (left pane + right pane) + a router entry (form title `jur:sg`) | HOST-06, COL-22, COL-39, COL-47 |
| `<SlotGrid name="cells" rows={3} cols={8}>` | `sg_panes`: three horizontal rows inside a vertical `stack_panel`, each row holding eight `item_toggle` cells (radio `toggle`, a fixed `collection_index` per cell) | COL-38, COL-50, INP-35 |
| `detail="Pick a slot."` | `sg_right` (the hint in the right pane) and `sg_detail` (the icon and name of the chosen cell's button). Switching a cell on shows the detail | INP-13, INP-35 |

## Opening it from the server

The behavior pack opens the screen with `openScreen(player, id, data)` from `scripts/generated/screens.js`, which `buildScreens` generates. The keys of `data` are the components' `name`s, and each value is a list of buttons. A button is `[text, icon]`. It returns a `Promise<null | { name, index }>`: `null` if the window is closed, otherwise which component (`name`) and which button in it (`index`) was pressed. Sending more buttons than the component has is an error, and missing ones are filled with the empty-cell mark (`§0§e§r`).

```js
import { openScreen } from "./generated/screens.js";

const ICONS = ["textures/items/diamond", "textures/items/apple", "textures/items/iron_ingot" /* ... */]; // the example cycles through 10
const NAMES = ["Diamond", "Apple", "Iron Ingot" /* ... */]; // the example cycles through 10

openScreen(player, "slot-grid", {
  // [name, icon] per cell
  cells: Array.from({ length: 24 }, (_, i) => [NAMES[i % NAMES.length], ICONS[i % ICONS.length]]),
}).then((hit) => {
  if (!hit) return; // canceled
  // hit: { name: "cells", index: 0..23 }
});
```

## Running it in the integration add-on

In the add-on you downloaded with "Download integration test add-on" at the top right, use the stick to pick the example in the picker, or run the command. In-game text is in English: the picker (`json-ui-react Examples`) lists this example as `Slot grid with selection detail`. Until you pick a slot, the detail area shows `Pick a slot.`.

24 buttons, form title `jur:sg`.

```text
/scriptevent jur:open slot-grid
```

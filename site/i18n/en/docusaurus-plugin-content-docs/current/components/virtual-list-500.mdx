# Virtual list, 500 cells

A two-column virtual list of 500 cells


`<VirtualList>` builds a two-column virtual list: a `grid` whose `maximum_grid_items` is bound to `#form_button_length`.

## APIs used

| Name | Description |
| --- | --- |
| `Screen` | One screen: [API reference](../api#high) |
| `VirtualList` | A scrolling grid list: [API reference](../api#high) |

## Writing it in JSX

`<VirtualList>` is the only child of the screen. `count` is the number of cells and `columns` defaults to 2. You cannot put anything else under `<Screen>`, and `layout` must be `single`. The two files below are the 500-cell entry point and the shared definition.

| High-level element | Lowered JSON UI | Rules |
| --- | --- | --- |
| `<Screen>` | List window `v5@jur.list_window` + a router entry (form title `jur:v5`) | HOST-06, COL-22, COL-39, COL-47 |
| `<VirtualList name="list" count={500} />` | `v5_list`: a `grid` with `maximum_grid_items` bound to `#form_button_length`. Each cell is a `list_cell` button | COL-49 |

## Opening it from the server

The behavior pack opens the screen with `openScreen(player, id, data)` from `scripts/generated/screens.js`, which `buildScreens` generates. The keys of `data` are the components' `name`s, and each value is a list of buttons. A button is `[text, icon]`. It returns a `Promise<null | { name, index }>`: `null` if the window is closed, otherwise which component (`name`) and which button in it (`index`) was pressed. Sending more buttons than the component has is an error, and missing ones are filled with the empty-cell mark (`§0§e§r`).

```js
import { openScreen } from "./generated/screens.js";

const ICONS = ["textures/items/diamond", "textures/items/apple" /* ... */]; // the example cycles through 10
const pad = (text, width) => (text + " ".repeat(width)).slice(0, width);

openScreen(player, "virtual-list-500", {
  // [text, icon] per cell. The text is name (12 chars) + description (20 chars) + a number
  list: Array.from({ length: 500 }, (_, i) => [
    pad(`Item ${i + 1}`, 12) + pad(`Description ${i + 1}`, 20) + String((i * 7) % 101),
    ICONS[i % ICONS.length],
  ]),
}).then((hit) => {
  if (!hit) return; // canceled
  // hit: { name: "list", index: 0..499 }
});
```

## Running it in the integration add-on

In the add-on you downloaded with "Download integration test add-on" at the top right, use the stick to pick the example in the picker, or run the command. In-game text is in English: the picker (`json-ui-react Examples`) lists this example as `Grid list (500)`.

500 buttons, form title `jur:v5`.

```text
/scriptevent jur:open virtual-list-500
```

# Tabs: shown by toggle state (method C)

Method C: panels follow a toggle-state binding to show or hide


A panel binds `#toggle_state` to `#visible`, so it follows the tab. A collection binding under the router needs `binding_condition: "always"`.

## Writing it in JSX

Uses `TabBar`, `SlotGrid` and `bind.view`. The panels show or hide by following a toggle-state binding.

| JSX | Lowered JSON UI |
| --- | --- |
| `<TabBar>` | Horizontal `stack_panel` + radio `toggle` with 8 states |
| `<SlotGrid>` | Row `stack_panel` + `collection_index` cells |
| `useTabs().paneBinding` | `#toggle_state` -> `#visible` binding |

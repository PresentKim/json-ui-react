# Tabs: built on first select (method D)

Method D: build a panel with a factory only when its tab is selected


Only the first tab is built up front. The rest are created by a factory bound to the toggle state when selected. You cannot use `lazyPane(0)` for the first tab.

| Name | Description |
| --- | --- |
| `TabBar` | [API reference](../api) |
| `SlotGrid` | [API reference](../api) |
| `bind.view` | [API reference](../api) |

## Writing it in JSX

Uses `TabBar`, `SlotGrid` and `bind.view`. A panel is created by a factory only when its tab is selected.

| JSX | Lowered JSON UI |
| --- | --- |
| `<TabBar>` | Horizontal `stack_panel` + radio `toggle` with 8 states |
| `<SlotGrid>` | Row `stack_panel` + `collection_index` cells |
| `useTabs().lazyPane` | `factory` + `#collection_length` binding |

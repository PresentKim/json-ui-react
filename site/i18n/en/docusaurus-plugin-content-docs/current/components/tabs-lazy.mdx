# Tabs: built on first select (method D)

Method D: build a panel with a factory only when its tab is selected


`<Tabs mode="lazy">` builds only the first tab up front. The other tabs are created, when selected, by a factory bound to the toggle state. A first tab built by a factory would be empty when the screen first opens, so the build creates the first tab up front automatically.

## APIs used

| Name | Description |
| --- | --- |
| `Screen` | One screen: [API reference](../api#high) |
| `Tabs` | Client-side tabs: [API reference](../api#high) |
| `Tab` | One tab: [API reference](../api#high) |
| `ButtonList` | A vertical list of icon + text buttons: [API reference](../api#high) |

## Writing it in JSX

Only `mode="lazy"` differs; the code has the same shape as method B. You do not need to treat the first tab specially.

| High-level element | Lowered JSON UI | Rules |
| --- | --- | --- |
| `<Screen>` | Window definition `tl@jur.window` + a router entry (form title `jur:tl`) | HOST-06, COL-22, COL-39, COL-47 |
| `<Tabs name="tabs" mode="lazy">` | Tab row `tl_tabs`: a horizontal `stack_panel` + radio `toggle` with 8 states | INP-10, INP-11, INP-13 |
| Content of the first `<Tab>` | `tl_pane_0` is built up front and shown only through the toggle-state binding | INP-13, COL-47 |
| Content of the other `<Tab>`s | `tl_lazy_1`: a `factory` plus a binding from the tab toggle to `#collection_length`. The pane is built when the tab is selected | INP-13, COL-47 |
| `<ButtonList name="tab1" count={2} />`, `<ButtonList name="tab2" count={2} />` | Two `@jur.btn` buttons per tab: 2 rows in a vertical `stack_panel` (`collection_name: form_buttons`), each with a fixed-`collection_index` cell | COL-38, COL-50 |

## Opening it from the server

The behavior pack opens the screen with `openScreen(player, id, data)` from `scripts/generated/screens.js`, which `buildScreens` generates. The keys of `data` are the components' `name`s, and each value is a list of buttons. A button is `[text, icon]`. It returns a `Promise<null | { name, index }>`: `null` if the window is closed, otherwise which component (`name`) and which button in it (`index`) was pressed. Sending more buttons than the component has is an error, and missing ones are filled with the empty-cell mark (`§0§e§r`).

```js
import { openScreen } from "./generated/screens.js";

openScreen(player, "tabs-lazy", {
  // <Tabs name="tabs">: tab text and icons
  tabs: [["Tab 1", "textures/items/book_normal"], ["Tab 2", "textures/items/emerald"]],
  // <ButtonList name="tab1" count={2}>, <ButtonList name="tab2" count={2}>
  tab1: [["Tab 1: Apple", "textures/items/apple"], ["Tab 1: Bread", "textures/items/bread"]],
  tab2: [["Tab 2: Diamond", "textures/items/diamond"], ["Tab 2: Gold Ingot", "textures/items/gold_ingot"]],
}).then((hit) => {
  if (!hit) return; // canceled
  // hit: { name: "tab1" | "tab2", index: 0..1 }
});
```

## Running it in the integration add-on

In the add-on you downloaded with "Download integration test add-on" at the top right, use the stick to pick the example in the picker, or run the command. In-game text is in English: the picker (`json-ui-react Examples`) lists this example as `Tabs: built on first select`.

6 buttons, form title `jur:tl`.

```text
/scriptevent jur:open tabs-lazy
```

# Router

A router that picks a screen by a 6-byte title prefix, plus a list of four buttons


One `<Screen>` and one `<ButtonList>` make a four-button screen. Picking the screen is left to the single router (`ScreenRouter`) that `buildScreens` generates. The router compares only the first 6 bytes of the form title (`jur:ro`), so every title has the same byte length. That is why the router never appears in the screen file.

## APIs used

| Name | Description |
| --- | --- |
| `Screen` | One screen: [API reference](../api#high) |
| `ButtonList` | A vertical list of icon + text buttons: [API reference](../api#high) |
| `buildScreens` | Builds the screens into one pack: [API reference](../api#high) |

## Writing it in JSX

Uses `<Screen>` and `<ButtonList>`. `<Screen>` takes an `id` (the name the behavior pack calls) and a `title` (shown at the top of the window). The `name` of `<ButtonList>` becomes the key in the server data, and `count` is 1 to 5 (what fits in the pane height). For a longer list, use `<VirtualList>`.

| High-level element | Lowered JSON UI | Rules |
| --- | --- | --- |
| `<Screen id="router" title="…">` | Window definition `ro@jur.window` (the title is a static label) + a router entry (form title `jur:ro`) | HOST-06, COL-22, COL-39, COL-47 |
| `<ButtonList name="buttons" count={4} />` | 4 `@jur.btn` buttons: 4 rows in a vertical `stack_panel` (`collection_name: form_buttons`), each with a fixed-`collection_index` cell | COL-38, COL-50 |

## Opening it from the server

The behavior pack opens the screen with `openScreen(player, id, data)` from `scripts/generated/screens.js`, which `buildScreens` generates. The keys of `data` are the components' `name`s, and each value is a list of buttons. A button is `[text, icon]`. It returns a `Promise<null | { name, index }>`: `null` if the window is closed, otherwise which component (`name`) and which button in it (`index`) was pressed. Sending more buttons than the component has is an error, and missing ones are filled with the empty-cell mark (`§0§e§r`).

```js
import { openScreen } from "./generated/screens.js";

openScreen(player, "router", {
  buttons: [
    ["Title prefix jur:", "textures/items/apple"],
    ["Lookup by 6 bytes", "textures/items/bread"],
    ["Pick one screen", "textures/items/diamond"],
    ["4 buttons in a row", "textures/items/emerald"],
  ],
}).then((hit) => {
  if (!hit) return; // canceled
  // hit: { name: "buttons", index: 0..3 }
});
```

## Running it in the integration add-on

In the add-on you downloaded with "Download integration test add-on" at the top right, use the stick to pick the example in the picker, or run the command. In-game text is in English: the picker (`json-ui-react Examples`) lists this example as `Screen router`.

4 buttons, form title `jur:ro`.

```text
/scriptevent jur:open router
```

# Router

A router that picks a screen by a 6-byte title prefix, plus a row of four buttons


`ScreenRouter` picks a screen with a `collection_panel`, a factory and a `property_bag` title lookup. It compares only the 6-byte title prefix (`jur:ro`), so every title must have the same byte length.

## Writing it in JSX

Uses `ScreenRouter`, `SlotGrid` and `createSlots`. This screen file draws only a row of four buttons (`ButtonRow` = a single `SlotGrid` row); the `ScreenRouter` that picks a screen by title is generated by the build script, which bundles all the examples.

| JSX | Lowered JSON UI |
| --- | --- |
| `<ScreenRouter>` | `collection_panel` + factory + `property_bag` title lookup |
| `<SlotGrid>` | Row `stack_panel` + `collection_index` cells |

## Running it in the integration add-on

In the add-on you downloaded with "Download integration test add-on" at the top right, use the stick to pick the example in the picker, or run the command. In-game text is in English: the picker (`json-ui-react Examples`) lists this example as `Screen router`.

Four buttons, form title `jur:ro`.

```text
/scriptevent jur:open router
```
